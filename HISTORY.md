# History

This repository is a snapshot. It was built in a private Gitea repository over
199 commits, under phase gates, and published as one commit taken
from `ac31b3a` (2026-10-02).

The records in this tree cite commits by SHA: the PHASE notes, the BUILD-LOGs,
`docs/DECISIONS.md`, `docs/STATUS.md` and the plans. Those SHAs belong to the private
history and do not resolve here. They are left as written, because rewriting a record
to point at commits that never held that work would be worse than a dangling
reference. Read a SHA as a name for "the change described in that sentence".
